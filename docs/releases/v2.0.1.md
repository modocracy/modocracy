# Modocracy v2.0.1

## 고친 점

- 분석판(`Modocracy-diagnostic.exe`)의 `log.txt`에 Windows 사용자 이름이 드러나지 않도록 했습니다. 사용자 폴더 경로(`C:\Users\이름\...`)는 `%USERPROFILE%\...`로 가려서 기록합니다. 오류 상세 기록에 들어가는 경로도 같이 가려집니다.
- 분석판 로그에 모니터 모델명을 더 이상 기록하지 않습니다. 해상도와 화면 배율만 남깁니다.
- 일반판(`Modocracy.exe`)은 이전과 같이 로그 파일을 만들지 않습니다.

v2.0.0 이상을 쓰고 있다면 창 위쪽의 `업데이트` 버튼으로 바로 업데이트할 수 있습니다. **v1.3.3 이하에서 올 때는 이번에도 `Modocracy.exe`를 직접 받아 기존 파일과 바꿔 주세요.** 자세한 내용은 [v2.0.0 안내](https://github.com/modocracy/modocracy/releases/tag/v2.0.0)를 참고하세요.

v2.0.0 분석판으로 만든 `log.txt`를 이미 가지고 있다면, 공유하기 전에 사용자 이름이 들어간 경로를 지우거나 v2.0.1 분석판으로 다시 기록해 주세요.

---

## Fixes

- The diagnostic build (`Modocracy-diagnostic.exe`) no longer reveals your Windows user name in `log.txt`. User folder paths (`C:\Users\name\...`) are written as `%USERPROFILE%\...`, including paths inside error details.
- The diagnostic log no longer records monitor model names; only resolution and scale are kept.
- The standard build (`Modocracy.exe`) still writes no log file.

If you are on v2.0.0 or later, just press `Update` in the banner at the top of the window. **If you are coming from v1.3.3 or earlier, download `Modocracy.exe` and replace your existing file manually.** See the [v2.0.0 notes](https://github.com/modocracy/modocracy/releases/tag/v2.0.0) for details.

If you already have a `log.txt` from the v2.0.0 diagnostic build, remove paths containing your user name before sharing it, or record a new log with the v2.0.1 diagnostic build.
