# Modocracy v2.0.0

## 기존 사용자: 이번 한 번은 수동 업데이트가 필요합니다

**v1.3.3 이하에서는 이번 버전으로 앱 안의 자동 업데이트를 할 수 없습니다. `Modocracy.exe`를 직접 받아 기존 실행 파일과 교체해 주세요.** 저장소를 `modocracy/modocracy`로 이전하면서, 구버전에 들어 있는 다운로드 주소 검증이 새 주소를 허용하지 못합니다.

앱에서 **[업데이트] 대신 [받으러 가기]**가 보이거나 **“이 릴리즈에는 자동 업데이트용 파일 정보가 없어요.”**라는 안내가 나오는 경우가 여기에 해당합니다. [받으러 가기] 또는 [변경 내용]을 누르면 이 릴리즈 페이지가 열립니다.

1. 실행 중인 Modocracy를 완전히 종료합니다.
2. 이 릴리즈의 Assets에서 **`Modocracy.exe`**를 받습니다.
3. 기존 `Modocracy.exe`와 바꾼 다음 새 파일을 실행합니다.

모드 보관 폴더와 설정은 유지됩니다. `%LOCALAPPDATA%\Modocracy`와 휴대용 `ModocracyData` 폴더는 삭제하지 마세요. 2.0.0은 새 저장소 주소를 사용하므로 이후 릴리즈부터 앱 안의 자동 업데이트를 다시 사용할 수 있습니다.

## 변경 내용

- 전용 화면을 **PySide6 + Qt Widgets**로 교체했습니다. 기본 실행 화면에 Edge/WebView2 런타임이 필요하지 않습니다.
- 모드 추가, 켜기·끄기, 옵션과 세부 선택, 우선순위 변경, 적용·제거·백업, 게임 실행과 한국어·영어 설정을 제공합니다. 기존 모드 보관함을 이어서 사용합니다.
- 필요한 Python·Qt 부품을 각각의 단일 exe에 포함했습니다. 압축을 풀어 놓은 배포 폴더나 별도의 Python·Qt 설치가 필요하지 않습니다.
- **`Modocracy.exe`**: 일반판입니다. 로그 파일을 생성하지 않습니다.
- **`Modocracy-diagnostic.exe`**: 문제 분석용입니다. 실행한 exe와 같은 폴더에 `log.txt`를 기록합니다. 분석판은 실행 파일 이름을 바꿔도 분석 모드로 실행되고, 이후 업데이트도 분석판 파일을 사용합니다.

문제를 제보할 때는 일반판을 완전히 종료한 뒤 분석판으로 같은 작업을 재현하고 `log.txt`를 첨부해 주세요. 로그는 자동으로 전송되지 않습니다. 로그가 1 MB를 넘으면 `log.txt.1`에 이전 기록을 보관합니다.

지원 대상은 Windows 10(1809 이상) / Windows 11 x64입니다. `.7z`·`.rar` 모드의 압축 해제에는 기존과 같이 7-Zip이 필요합니다.

## Existing users: a one-time manual update is required

**Versions 1.3.3 and earlier cannot install this release through the in-app automatic updater. Download `Modocracy.exe` directly and replace your existing executable.** The repository moved to `modocracy/modocracy`, and older builds reject the new download URL.

If the app shows **[Download] instead of [Update]**, or **“This release has no file information for automatic updates.”**, this repository move is the reason. [Download] and [What's new] open this release page.

1. Close every running Modocracy window.
2. Download **`Modocracy.exe`** from this release's Assets.
3. Replace your existing `Modocracy.exe`, then run the new file.

Your mod library and settings are preserved. Keep your `%LOCALAPPDATA%\Modocracy` or portable `ModocracyData` folder. Version 2.0.0 uses the new repository address, so in-app automatic updates can be used again for subsequent releases.

## Changes

- Replaced the app window with **PySide6 + Qt Widgets**. The default interface no longer needs Edge or the WebView2 Runtime.
- Includes mod import, enable/disable, options and suboptions, priority ordering, apply/remove/backup, game launch, and Korean/English settings. Existing mod libraries remain usable.
- Python and Qt components are bundled into each standalone executable. No separate Python/Qt installation or extracted distribution folder is required.
- **`Modocracy.exe`**: the standard build; creates no log file.
- **`Modocracy-diagnostic.exe`**: the diagnostic build; writes `log.txt` beside the executable. Renaming this executable preserves diagnostic mode, and its updater continues to download diagnostic builds.

To report a problem, fully close the standard build, reproduce the issue in the diagnostic build, and attach `log.txt`. Logs are not uploaded automatically. After 1 MB, the previous log is retained as `log.txt.1`.

Supported systems: Windows 10 (1809 or later) / Windows 11 x64. As before, importing `.7z` and `.rar` mods requires 7-Zip.
