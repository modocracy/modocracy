# Modocracy v2.0.2

## 고친 점

- 창이 뒤에서 모드 정보를 새로 불러오는 동안(켤 때 업데이트 확인, 15초마다 새로고침) 옵션을 연달아 바꾸면 앞에서 바꾼 옵션이 되돌아가던 문제를 고쳤습니다. 순서를 옮길 때도 같은 문제가 없습니다.
- 그 사이에 모드를 켜거나 끄고 바로 창을 닫으면 변경이 저장되지 않던 문제를 고쳤습니다. 이제 받은 변경을 모두 저장한 뒤 창이 닫힙니다.
- 게임 실행 여부처럼 모드와 상관없는 상태가 바뀌어도, 펼쳐 둔 선택 상자나 보고 있던 상세 화면이 다시 그려져 닫히지 않습니다.
- 모드 목록에서 **스페이스바**로 선택한 모드를 켜고 끌 수 있습니다. Tab으로 이동하면 스위치·체크 상자·목록에 노란 테두리로 현재 위치가 보입니다.
- 분석판 로그 개인정보 보호를 보강했습니다.
  - `C:\Users\JANEDO~1` 같은 짧은 경로 표기도 `%USERPROFILE%`로 가립니다.
  - 이름이 겹치는 다른 사용자 폴더(예: `Jane Doe`일 때 `Jane Doe Smith`)는 잘못 가리지 않습니다.
  - v2.0.0 분석판이 남긴 기존 `log.txt`·`log.txt.1`도 분석판을 켤 때 자동으로 가립니다.
- 목록의 빈 곳에 마우스를 올렸을 때 엉뚱한 안내가 뜨던 문제를 고쳤습니다.

v2.0.0 이상을 쓰고 있다면 창 위쪽의 `업데이트` 버튼으로 바로 업데이트할 수 있습니다. **v1.3.3 이하에서 올 때는 `Modocracy.exe`를 직접 받아 기존 파일과 바꿔 주세요.** 자세한 내용은 [v2.0.0 안내](https://github.com/modocracy/modocracy/releases/tag/v2.0.0)를 참고하세요.

## Fixes

- Fixed earlier option changes being reverted when several options were changed while the window refreshed mod information in the background (the startup update check and the 15-second refresh). Reordering mods is covered too.
- Fixed changes being lost when a mod was toggled during that refresh and the window was closed right away. The window now saves every pending change before closing.
- Changes unrelated to mods, such as the game starting, no longer redraw the details panel and close an open drop-down.
- Press **Space** in the mod list to toggle the selected mod. When moving with Tab, switches, checkboxes and the list show a yellow focus outline.
- Stronger privacy for diagnostic logs:
  - Short 8.3 paths such as `C:\Users\JANEDO~1` are also written as `%USERPROFILE%`.
  - Other user folders whose names start the same way (for example `Jane Doe Smith` when you are `Jane Doe`) are no longer masked by mistake.
  - Existing `log.txt` and `log.txt.1` files written by the v2.0.0 diagnostic build are masked automatically when the diagnostic build starts.
- Fixed a stray tooltip when hovering over empty space in the mod list.

If you are on v2.0.0 or later, just press `Update` in the banner at the top of the window. **If you are coming from v1.3.3 or earlier, download `Modocracy.exe` and replace your existing file manually.** See the [v2.0.0 notes](https://github.com/modocracy/modocracy/releases/tag/v2.0.0) for details.
