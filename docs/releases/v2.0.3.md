# Modocracy v2.0.3

## 고친 점

- **manifest 없이 부분별 폴더로 나뉜 모드를 모두 함께 설치합니다.** 예를 들어 [Helldivers 2 Optimized MOD](https://www.nexusmods.com/helldivers2/mods/16573)처럼 `City LOD`, `NPC Texture` 같은 폴더에 서로 다른 파일이 들어 있으면, 이전에는 "버전 고르기 (하나만)"로 표시돼 폴더 하나만 설치할 수 있었습니다. 이제 폴더마다 켜고 끌 수 있는 옵션으로 표시되고, 처음에는 모두 켜져 있습니다.
  - 폴더마다 같은 파일의 다른 버전이 들어 있는 모드(예: 색상별 버전)는 지금처럼 하나만 고릅니다.
  - 이미 추가해 둔 모드에도 바로 적용됩니다. 옵션을 확인한 뒤 **[적용하기]를 한 번 다시 눌러 주세요.**
- **게임 폴더에 다른 모드 파일이 많을 때 확인 창이 화면 밖으로 넘어가 버튼을 누를 수 없던 문제를 고쳤습니다.** 파일 목록은 창 안에서 스크롤되고, 버튼은 항상 창 아래에 보입니다. 다른 확인·오류 창도 같은 방식으로 바꿨습니다.

v2.0.0 이상을 쓰고 있다면 창 위쪽의 `업데이트` 버튼으로 바로 업데이트할 수 있습니다. **v1.3.3 이하에서 올 때는 `Modocracy.exe`를 직접 받아 기존 파일과 바꿔 주세요.** 자세한 내용은 [v2.0.0 안내](https://github.com/modocracy/modocracy/releases/tag/v2.0.0)를 참고하세요.

## Fixes

- **Mods without a manifest that are split into part folders are now installed together.** For example, [Helldivers 2 Optimized MOD](https://www.nexusmods.com/helldivers2/mods/16573) ships different files in folders such as `City LOD` and `NPC Texture`. It used to be shown as "Choose a version (only one)", so only one folder could be installed. Each folder is now an option you can toggle, and all of them start enabled.
  - Mods whose folders hold different versions of the same files (for example color variants) still let you pick one.
  - This also applies to mods you already added. Check the options, then **press [Apply] once more.**
- **Fixed the confirmation window growing past the screen when the game folder contains many other mod files, which hid its buttons.** The file list now scrolls inside the window and the buttons always stay at the bottom. Other confirmation and error windows use the same layout.

If you are on v2.0.0 or later, just press `Update` in the banner at the top of the window. **If you are coming from v1.3.3 or earlier, download `Modocracy.exe` and replace your existing file manually.** See the [v2.0.0 notes](https://github.com/modocracy/modocracy/releases/tag/v2.0.0) for details.
