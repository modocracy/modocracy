# Modocracy v2.0.4

## 고친 점

- manifest가 없는 모드의 이름에서 Nexus가 내려받을 때 붙이는 모드 번호·버전·날짜를 뗍니다.
  - 예: `Helldivers 2 Optimizer 1.1 16573 1.1 2026-09-27T13-31Z 2Gg9W5DlI` → `Helldivers 2 Optimizer 1.1`
  - 이미 추가해 둔 모드의 이름도 자동으로 정리됩니다. 다시 추가하거나 적용할 필요는 없습니다.
  - manifest에 이름이 적힌 모드와, 꼬리가 없는 파일 이름은 그대로 둡니다.

v2.0.0 이상을 쓰고 있다면 창 위쪽의 `업데이트` 버튼으로 바로 업데이트할 수 있습니다. **v1.3.3 이하에서 올 때는 `Modocracy.exe`를 직접 받아 기존 파일과 바꿔 주세요.** 자세한 내용은 [v2.0.0 안내](https://github.com/modocracy/modocracy/releases/tag/v2.0.0)를 참고하세요.

---

## Fixes

- Mods without a manifest no longer show the mod id, version and date that Nexus appends to downloaded file names.
  - Example: `Helldivers 2 Optimizer 1.1 16573 1.1 2026-09-27T13-31Z 2Gg9W5DlI` → `Helldivers 2 Optimizer 1.1`
  - Mods you already added are renamed automatically. You don't need to add or apply them again.
  - Names from a manifest, and file names without the Nexus suffix, are left unchanged.

If you are on v2.0.0 or later, just press `Update` in the banner at the top of the window. **If you are coming from v1.3.3 or earlier, download `Modocracy.exe` and replace your existing file manually.** See the [v2.0.0 notes](https://github.com/modocracy/modocracy/releases/tag/v2.0.0) for details.
